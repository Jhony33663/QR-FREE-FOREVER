# QR-FREE-FOREVER

Generador de codigos QR con branding personalizado, logos centrales y exportacion en multiples formatos.

## Autor

- Jonathan David Mata (`C0d3k`)

## Desarrollo local

**Requisitos:** Node.js

1. Instala dependencias con `npm install`
2. Configura `GEMINI_API_KEY` en `.env.local`
3. Inicia el proyecto con `npm run dev`
